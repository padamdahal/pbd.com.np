How to use this calendar on any website

You can either embed a simple month view with an iframe, or include the library script so that click-to-copy and drag-to-fill work on your own forms.

1. Simple embed (iframe)

Best when you only need a visual calendar. Users can still click days to copy the ISO date inside the iframe.

<iframe
  src="https://pbd.com.np/tools/nepali-calendar/"
  title="Nepali Calendar (BS)"
  width="100%"
  height="520"
  style="border:0;border-radius:12px;max-width:400px"
  loading="lazy"></iframe>

2. Full interactive calendar on your own page (recommended for forms)

Add the script once, then mount the calendar wherever you want. Drag-and-drop and clipboard copy will work for every input on that page.

<!-- 1. Include the library (once per page) -->
<script src="https://pbd.com.np/tools/nepali-calendar/nepali-calendar.js"></script>

<!-- 2. Place a container -->
<div id="my-calendar"></div>

<!-- 3. Mount it -->
<script>
  NepaliCalendar.mount('#my-calendar', {
    lang: 'ne',          // 'ne' or 'en'
    theme: 'light',      // 'light' | 'dark' | 'auto'
    timeZone: 'Asia/Kathmandu',
    showAD: true,
    langToggle: true
  });
</script>
Drag-to-fill tip: After the script is loaded, any day cell can be dragged onto a normal <input> or <textarea> on the same page. The field receives the ISO date (yyyy-mm-dd). Readonly fields are filled by default (useful for many date pickers).

3. Auto-mount with a data attribute

If you prefer zero JavaScript on your side:

<div data-nepali-calendar
     data-lang="ne"
     data-theme="auto"
     data-time-zone="Asia/Kathmandu"></div>
<script src="https://pbd.com.np/tools/nepali-calendar/nepali-calendar.js"></script>

Useful API helpers

// Convert a single date
NepaliCalendar.toAD(2082, 7, 16);   // → "2025-11-02"
NepaliCalendar.toBS("2025-11-02");  // → { year: 2082, month: 7, day: 16 }

// Today in Nepal time
NepaliCalendar.today("Asia/Kathmandu");
// → { iso: "2025-11-02", bs: { year: 2082, month: 7, day: 16 } }

Frequently asked questions

How do I copy a date?

Click any day (or focus it with the keyboard and press Enter). The Gregorian ISO date is copied to the clipboard and a short confirmation appears.

How does drag-to-fill work?

Drag a day cell and drop it on any text, date, search or similar input (or textarea) on the same page. The field is set to the ISO date. This works even if the input is readonly.

What BS years are supported?

BS 2000–2090 (approximately AD 1943–2034). Years through 2083 are verified against two independent sources. Later years are shown with a provisional warning because sources can disagree on exact month lengths.

Can I use this calendar on my own website or form?

Yes. Use the iframe for a simple embed, or include the nepali-calendar.js script and call NepaliCalendar.mount() so that click-to-copy and drag-to-fill work on your forms.

Does it work offline?

Yes. After the first visit the page and library work fully offline. Nothing is sent to a server.

Is the data accurate for official documents?

The calendar table matches common sources used in Nepal for banks and forms. Always double-check critical legal or financial dates, especially near year boundaries or for years after BS 2083.
