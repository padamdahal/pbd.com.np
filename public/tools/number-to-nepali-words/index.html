Number to Nepali words

Type a number in English or Nepali digits. Get the amount in words for cheques, bills and forms — लाख, करोड, अर्ब, खर्ब. Free and private. Also available as a reusable JavaScript library.

Formatted

In words / अक्षरमा

Tip: Turn on Cheque mode for ready-to-paste text ending with “मात्र”. Always double-check before signing any legal document.

How to use

  1. Type or paste a number. Commas are fine. Nepali digits work too.
  2. Words update as you type, grouped the Nepali way (pairs after the first three).
  3. Optionally enable Cheque mode for “रुपैयाँ … मात्र” format.
  4. Copy the words. Check them before using on a legal document.

Frequently asked questions

How do I convert a number to Nepali words?

Type any number in English or Nepali digits. The tool writes it using लाख, करोड, अर्ब and खर्ब.

Can I use Nepali digits like १२३?

Yes. English digits and Nepali digits both work, including decimals.

Is this useful for cheques in Nepal?

Yes. Enable Cheque mode to get the amount with रुपैयाँ and मात्र. Always double-check before you sign.

Can I use this library on my own website?

Yes. Include the free script and call NepaliNumberToWords.toWords(). See the developer documentation below.

Developer documentation

This tool is also a free, zero-dependency JavaScript library. You can use it on any webpage (including your own site) without sending data to our servers.

1. Include the script

<script src="https://pbd.com.np/tools/number-to-nepali-words/number-words.js"></script>

After the script loads, the global object NepaliNumberToWords is available.

2. Basic usage

// Plain words NepaliNumberToWords.toWords(125000); // → "एक लाख पच्चीस हजार" NepaliNumberToWords.toWords("12,50,000.50"); // → "बारह लाख पचास हजार दशमलव पाँच शून्य" // Cheque / currency style NepaliNumberToWords.toWords(125000.50, { currency: true }); // → "एक लाख पच्चीस हजार रुपैयाँ पचास पैसा मात्र" NepaliNumberToWords.toWords(5000, { currency: true }); // → "पाँच हजार रुपैयाँ मात्र"

3. API reference

Method Description
toWords(value, options?) Converts a number (string, number or BigInt) to Nepali words.
Options:
currency: boolean (default false) — adds “रुपैयाँ … मात्र” (and पैसा when decimals are present).
includeDecimalWords: boolean (default true) — when not in currency mode, appends “दशमलव …”.
formatGrouped(digits) Formats a digit string with Nepali comma grouping (last 3 digits, then pairs). Example: "1250000" → "12,50,000".
parse(value) Returns { raw, grouped, negative, fraction } or null if invalid. Useful for building your own UI.
version Current library version string (e.g. "1.1.0").

4. Features & limits

  • Supports English digits, Nepali (Devanagari) digits, commas and spaces.
  • Negative numbers → prefix “ऋण”.
  • Decimals supported (up to 8 places; currency mode uses first two digits as पैसा).
  • Up to 19 integer digits (covers शंख and beyond for practical use).
  • No external dependencies. Runs 100% in the browser.
  • Works offline once the script has been cached.

5. Example – live conversion on your page

<input id="amount" type="text" placeholder="Enter amount"> <p id="result"></p> <script src="https://pbd.com.np/tools/number-to-nepali-words/number-words.js"></script> <script> const input = document.getElementById("amount"); const result = document.getElementById("result"); input.addEventListener("input", () => { result.textContent = NepaliNumberToWords.toWords(input.value, { currency: true }); }); </script>
Stability note: The script URL above is the stable public endpoint. We keep the API backward-compatible. Current version: 1.1.0.
